# Random Password Generator

**Автор:** Тюхтин 

## Описание

Простое GUI-приложение для генерации случайных паролей с настройкой длины и типов символов. История паролей сохраняется в файл JSON.

## Требования

- Python 3.x
- Библиотека Tkinter (входит в стандартную поставку Python)

## Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourname/password-generator.git
   ```
2. Перейдите в папку:
   ```
   cd password-generator
   ```
3. Запустите приложение:
   ```
   python password_generator.py
   ```

## Возможности

- Выбор длины пароля (от 4 до 32 символов).
- Включение/выключение цифр, букв и спецсимволов.
- История сгенерированных паролей (сохраняется в `password_history.json`).
- Проверка корректности ввода.

## Примеры использования

1. Запустите программу.
2. Установите ползунком нужную длину.
3. Отметьте нужные типы символов.
4. Нажмите «Сгенерировать».
5. Сгенерированный пароль появится в поле и добавится в таблицу истории.
